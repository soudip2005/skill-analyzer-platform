About Skill Analyzer

Bridging the gap between claiming a skill on a resume and actually proving it.

How It Works

  • Analyze: Take a timed 30-question test consisting of MCQs, fill-in-the-blanks, and live code debugging.
  • Track: View your detailed performance analytics and radar charts on your private dashboard.
  • Build: Automatically generate an ATS-friendly PDF resume that highlights your verified scores.

Technology Stack

This platform is engineered using a robust Flask Python backend, a PostgreSQL relational database for secure data management, and dynamic HTML/CSS/JS with a modern glassmorphism user interface.
